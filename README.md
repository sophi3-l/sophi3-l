Embedded systems and hardware engineer. Senior at UNC Chapel Hill, B.A. Engineering Physics (Honors) with a minor in Applied Sciences and Engineering, graduating May 2027.

I build electronics that have to survive somewhere difficult: firmware, PCBs, and test rigs for deep-sea instruments, field robots, and clinical prototyping. I'm looking for embedded and hardware roles in medtech, biotech, and sensor systems.

## Projects

**[Deep-sea sequential water sampler](https://github.com/sophi3-l/Servo-Valve-Sample)** · ESP32, C++, PlatformIO
Firmware for an autonomous sampler that drives 21 servo pinch valves through two PCA9685 drivers on deep-sea landers. Deep-sleep mission scheduling, per-unit calibration stored in NVS so one binary runs the whole fleet, a Wi-Fi service UI, and CI that validates calibration headers and builds every environment.

**[SHT3x I²C test utility](https://github.com/sophi3-l/sht3x-test)** · Python, Linux, I²C
Dual-sensor temperature and humidity reader for embedded Linux boards, with Sensirion CRC checking and bus scanning. Written for thermal soak testing.

**Ramphibian** · Project Lead, Ram Engineering
Tracked robot for pressure-washing campus stairwells, built with UNC Facilities. Safety analysis, plumbing design, and a phased budget.

**Teleoperated robot arm** · Project Lead, Ram Engineering
Led a six-person team through the V2 arm. Makerfest winner.
